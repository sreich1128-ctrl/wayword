# Wayword principles

Every change is checked against these. If a feature can't say how it respects all five, it waits.

1. **Useful over complete.** Only phrases a tourist will actually say. No word lists for their own sake.
2. **Speaking is the finish line.** Listening, reading and building exist to get you to say it out loud.
3. **Learning science, invisible.** Chunks over rules. Spacing, retrieval and feedback happen inside the flow; nobody has to learn grammar terms or a system.
4. **Hooked, not fooled.** Only reward real skill acts (a right answer, a phrase said, a review kept). No points for opening the app, no streak to lose.
5. **Simple flow.** The next step is obvious in one glance. New features fit into an existing step before they get a new one.

## How recent features respect them (2026-11)

- **Karaoke** (each word lights up as it's said): no new button or screen (5); links the sound to the written phrase, the step before saying it (2, 3).
- **Tap a word to hear it**: the word is cut from the phrase recording, so it's the sound you'll hear in the street, not a dictionary form (1, 2). No word meanings: the phrase is learned as a chunk (3).
- **Hear it, then build it**: a second way to ask the existing Build step, in reviews only, not a new step type (5). Counts only when you build it right (4).
